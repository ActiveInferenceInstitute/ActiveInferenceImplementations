# Documentation — ActiveInferenceImplementations

Documentation index for **`ActiveInferenceInstitute/ActiveInferenceImplementations`**,
an educational Julia notebook repository maintained by the Active Inference
Institute. Start with [`../README.md`](../README.md) for the overview, then use
this hub for the layout, the gates, and the measured numbers behind them.

The flat list of every long-lived page is
[`documentation-index.md`](documentation-index.md).

## Gates

[`../run.sh`](../run.sh) is the single entry point; `.github/workflows/ci.yml`
calls the same arms. `./run.sh --list` prints them.

| Arm | Covers |
| --- | --- |
| `lint` | Julia parse check, Python compile check, JSON validity, `bash -n run.sh` |
| `test-fast` | Static gates only: specification declarations, spec-reader refusal, seeded data, notebook API guard. No RxInfer, no inference. |
| `test` | The full suite; includes the static gates and the mean-field VMP inference checks |
| `docs` | Relative links and heading anchors, plus the generated gate table |
| `gnn` | GNN conformance against the pin record |
| `notebooks` | Both notebooks executed into `_build/executed` |

`./run.sh` with no argument runs `test-fast`. The measured per-arm numbers are
in [`gate-timings.md`](gate-timings.md), not in prose.

There is no separate type-check arm: the repository has no typed-Python
toolchain, and Julia checks the code it loads. The `lint` arm parses every Julia
source without loading it, compiles the Python scripts, and validates the JSON
records and the shell script.

## Status

The notebooks and the Julia test suite work from a clean checkout after
`./run.sh setup`. The GNN conformance gate needs network access the first time to
provision the pinned parser runtime, or a local GNN checkout plus a matching
parser runtime; without either it exits `2`, which means *not run*, never a
pass. Documentation itself needs no Julia or notebook execution.
