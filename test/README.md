# Test suite

Two files, two arms of [`../run.sh`](../run.sh):

| File | Arm | Needs RxInfer | Checks |
| --- | --- | --- | --- |
| `static_tests.jl` | `./run.sh test-fast` (default) | no | specification declarations, spec-reader refusal of incomplete documents, seeded data reproducibility, notebook API guard |
| `runtests.jl` | `./run.sh test` | yes | includes the static gates and adds the mean-field VMP recovery checks |

Run from the repository root:

```bash
./run.sh setup        # once per environment
./run.sh test-fast
./run.sh test
```

The same commands without `run.sh`, if you want them directly:

```bash
julia --project=. -e 'using Pkg; Pkg.instantiate()'
julia --project=. test/static_tests.jl
julia --project=. test/runtests.jl
```

CI runs `./run.sh test` on Julia 1.13 in
[`.github/workflows/ci.yml`](../.github/workflows/ci.yml); `test-fast` is the
local default and is covered by the full run.

`runtests.jl` reads the declarations from `specs/normal_vmp.gnn.md` through
`src/spec_reader.jl` and checks:

- the declared model name, priors, data statistics, observation count, VMP
  iteration count, and seed;
- that the seeded data is reproducible and matches the declared mean and
  precision within the stated tolerances;
- that mean-field VMP recovers the declared data statistics and reduces free
  energy;
- that the notebooks use the current RxInfer API and do not fall back to the
  retired reactive interface;
- that the notebooks point at their canonical GNN documents.

The measured pass counts and wall times are in
[`../docs/gate-timings.md`](../docs/gate-timings.md), generated by
`python3 scripts/measure_gates.py`.
