# Test suite

The two Julia arms of [`../run.sh`](../run.sh) separate static checks from
independent inference recovery. Python regressions exercise the validator's
CLI, failure domains, archive lifetime, and actual pinned-runtime contracts:

| File | Arm | Needs RxInfer | Checks |
| --- | --- | --- | --- |
| `static_tests.jl` | `./run.sh test-fast` (default) | no | declarations, exact integer spellings/refusals/ranges, seeded data, retired notebook API-token guard |
| `runtests.jl` | `./run.sh test` | yes | includes static gates and adds independent mean-field VMP recovery |
| `test_validate_gnn_spec.py` | Python unittest; included by `./run.sh gnn` | no | offline CLI/input/error-domain and owned Git-archive regressions |
| `test_validate_gnn_spec_runtime.py` | Python unittest with explicit runtime admission | no | actual pinned parser, Julia reader, source-selection, JSON receipt, rejection, and archive-cleanup contracts |

Run from the repository root:

```bash
./run.sh setup        # once per environment
./run.sh test-fast
./run.sh test
```

The same commands without `run.sh`, if you want them directly:

```bash
julia --project=. -e 'using Pkg; Pkg.instantiate()'
julia --project=. test/static_tests.jl
julia --project=. test/runtests.jl
```

CI runs `./run.sh test` on Julia 1.13 in
[`.github/workflows/ci.yml`](../.github/workflows/ci.yml); `test-fast` is the
local default and is covered by the full run.

`runtests.jl` includes the static declaration, exact-integer, seeded-data, and
retired-API-token checks, then runs an independent mean-field VMP model and
checks recovered statistics and free energy. Canonical-document signposts are
checked by the Python validator. Neither Julia suite executes a notebook or
compares its retained posterior outputs.

To exercise the Python files against already-prepared runtimes:

```bash
GNN_RUNTIME_PYTHON=/path/to/pinned-runtime/bin/python \
JULIA_BIN=/path/to/julia \
  python3 -B -m unittest discover -s test -p 'test_validate_gnn_spec*.py'
```

Actual-runtime cases require the existing exact-pin parser and Julia; archive
cases require Git. These tests do not provision dependencies or fetch source.
Missing prerequisites may skip cases, but skips do not establish acceptance.

The measured pass counts and wall times are in
[`../docs/gate-timings.md`](../docs/gate-timings.md), generated by
`python3 scripts/measure_gates.py`.
